# Christmas Night Portfolio — Giang Văn Huấn

Portfolio cá nhân với chủ đề Đêm Noel (Christmas Night), xây dựng bằng HTML5, CSS3 và JavaScript.

## Tính năng
- Giao diện chủ đề đêm Giáng Sinh: bầu trời đêm, cây thông, quà và ánh đèn.
- Hiệu ứng tuyết rơi bằng Canvas; có nút bật/tắt tuyết.
- Menu điều hướng thu gọn trên điện thoại.
- Các phần: Trang chủ, Giới thiệu, Kỹ năng, Dự án, Hành trình, Liên hệ.
- Responsive với CSS Grid, Flexbox và media queries.

## Chạy trên VS Code
1. Giải nén thư mục.
2. Mở thư mục bằng VS Code.
3. Mở `index.html` bằng Live Server hoặc trình duyệt.

## Triển khai GitHub Pages
Đưa toàn bộ nội dung lên repository, vào Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. Dùng URL GitHub Pages được GitHub cấp để kiểm tra.

## Cần cá nhân hóa
- Thêm ảnh chân dung nếu muốn.
- Bổ sung email liên hệ.
- Kiểm tra và cập nhật mô tả dự án đúng tiến độ thực tế.
- Tự kiểm thử trên điện thoại, máy tính và chụp minh chứng thật.

Lưu ý: cây thông và quà được tạo bằng CSS; tuyết rơi được vẽ bằng Canvas. Nhạc nền chưa được tích hợp; có thể bổ sung tệp âm thanh có quyền sử dụng phù hợp.
